# Advanced Analytics Portfolio

A portfolio of retail analytics case studies covering SQL, Python analysis, KPI documentation, dashboard planning, and business recommendations.

## Project Areas

- Customer segmentation and retention
- Store performance analytics
- Sales forecasting and trend analysis
- Google ratings and review performance
- Dashboard KPI documentation
- Experiment and cohort analysis

## Structure

```text
case-studies/   Business case writeups
sql/            SQL analytics solutions
python/         Python analysis scripts
charts/         Generated sample chart data / outputs
docs/           KPI glossary, roadmap, and project log
dashboards/     Dashboard specs and wireframes
```
